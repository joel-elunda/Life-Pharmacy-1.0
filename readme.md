# 💊 Life Pharmacy POS

## 📌 Description
**Life Pharmacy POS** est une application de facturation et gestion des produits pharmaceutiques développée en **JavaFX** avec une architecture **MVC**.  
Elle permet de gérer les **produits, clients, fournisseurs, factures, recettes et utilisateurs** avec un contrôle d'accès basé sur les rôles.

---

## 🚀 Fonctionnalités principales
- 🔑 **Authentification** (Admin / Manager / Caissier)
- 📦 **Gestion Produits** (ajout, modification, suppression, recherche, import/export)
- 🧑‍🤝‍🧑 **Gestion Clients**
- 🏭 **Gestion Fournisseurs**
- 🧾 **Facturation** avec génération automatique des détails de facture
- 💰 **Recettes** (filtres par période et méthode de paiement, affichage graphique)
- 📊 **Dashboard** avec statistiques de ventes
- 📤 **Export Excel / JSON** (Produits, Clients, Factures, Fournisseurs)
- 📥 **Import Excel / JSON**

---

## 🛠️ Technologies utilisées
- **Java 21**
- **JavaFX 21** (FXML + CSS)
- **SQLite** (DB intégrée)
- **Maven** (gestion des dépendances)
